# 🎮 Survivor Chronicles

**Survivor Chronicles** — это 2D-игра в жанре песочница (top-down ¾ view) с процедурной генерацией мира, крафтом, строительством и элементами выживания. Проект разработан в качестве дипломной работы.

## 🚀 Играть онлайн
Вы можете запустить игру прямо в браузере без установки:  
👉 **[Играть на itch.io](https://[ТВОЙ_НИК].itch.io/survivor)**

## ✨ Основные механики
* 🌍 **Процедурная генерация** — мир создаётся случайно (с использованием Seed), деревья и камни расставляются без пересечений.
* ⛏ **Сбор ресурсов** — добыча дерева и камня с визуальным прогресс-баром.
* ⚒️ **Крафт и строительство** — создание стен, домов и инструментов (только рядом с верстаком!).
* 🌙 **Цикл дня и ночи** — каждые 5 минут время суток меняется, ночью появляется больше зомби.
* ⚔️ **Боевая система** — атака врагов по клику с кулдауном, разный урон от разных инструментов.
* 🎒 **Инвентарь** — 6 слотов быстрого доступа (хотбар) и полный инвентарь на 48 ячеек.
* 💾 **Сохранение прогресса** — сохранение позиции, инвентаря, построек и Seed-а мира в JSON (работает в WebGL через IndexedDB).

## 🕹 Управление
| Клавиша | Действие |
|---|---|
| **WASD** | Движение |
| **ЛКМ** | Копать / Атаковать / Ставить предмет |
| **C** | Открыть меню крафта (у верстака) |
| **F** | Режим строительства (стены, дома) |
| **1-6** | Выбор слота в хотбаре |
| **R** | Повернуть объект при строительстве |
| **E** | Взаимодействие с верстаком |
| **Esc** | Меню паузы |
| **F5 / F9** | Сохранить / Загрузить игру |

## 🛠 Технологии
* **Движок:** Unity 2022.3 LTS
* **Язык:** C# (.NET Standard 2.1)
* **Платформа:** WebGL (браузер)
* **Графика:** 2D, пиксель-арт, Y-Sorting
* **Сохранения:** JSON (Application.persistentDataPath)

## 📂 Архитектура
Проект написан по принципу **«Один класс = одна ответственность»** и разделён на модули:
* `Player/` — управление, здоровье, копание, строительство.
* `World/` — генерация, тайлмапы, день/ночь, спавн объектов.
* `Inventory/` & `Crafting/` — инвентарь, рецепты (ScriptableObjects), крафт.
* `Entities/` — ИИ врагов (зомби), логика урона.
* `SaveSystem/` — сохранение и загрузка данных.
* `UI/` — меню, миникарта, интерфейс инвентаря.
* `Utilities/` — вспомогательные скрипты.
